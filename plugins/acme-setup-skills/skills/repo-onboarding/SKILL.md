# Repo onboarding

1. Read `CLAUDE.md` first.
2. Summarise the layout of the source and test folders (one line per top-level folder).
3. Give the setup path from `CLAUDE.md`.
4. Point out the entry points that `CLAUDE.md` names.
5. List the three riskiest areas to change, using the Gotchas in `CLAUDE.md`.
6. Never open `.env*` files; refer to `.env.example` (if the repo has one) for variable names.
